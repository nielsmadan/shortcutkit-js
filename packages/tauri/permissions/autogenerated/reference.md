## Default Permission

Allows every ShortcutKit command: the state file, global hotkeys, keyboard layout and system shortcuts.

#### This default permission set includes the following:

- `allow-load-state`
- `allow-save-state`
- `allow-sync-global-hotkeys`
- `allow-detach-global-hotkeys`
- `allow-global-hotkeys-state`
- `allow-keyboard-layout`
- `allow-system-shortcuts`
